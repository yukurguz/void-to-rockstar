# M-Vave SMK-37 по Bluetooth MIDI на Windows

Инструкция, как подключить клавиатуру M-Vave SMK-37 к ноутбуку с Windows без провода и настроить её в Ableton Live, FL Studio и Cubase.

Проверено на: SMK-37 Elite, Windows 11 25H2, loopMIDI 1.0.16.27, MIDIberry 1.4.0.0. На Windows 10 схема та же, но там я её не проверял.

## Почему клавиатура «не подключается»

Сопряжение по Bluetooth обычно проходит нормально, но программы клавиатуру не видят. Причина в Windows: Bluetooth MIDI доступен только через новый системный интерфейс, а большинство музыкальных программ (и фирменный MidiSuite от M-Vave) берут список MIDI-устройств из старого. В старом списке клавиатуры просто нет.

Решение — «мост» из двух бесплатных программ:

- **loopMIDI** создаёт виртуальный MIDI-порт, который видят все программы.
- **MIDIberry** принимает ноты с клавиатуры по Bluetooth и пересылает их в этот порт.

```
Клавиатура ──Bluetooth──> MIDIberry ──> порт loopMIDI ──> Ableton / FL Studio / Cubase
```

Если нужен только MidiSuite (настройки клавиатуры, прошивка), ничего из этого не требуется: подключите клавиатуру USB-кабелем. Через Bluetooth-мост MidiSuite работать не будет, см. раздел «Ограничения».

## Шаг 1. Сопряжение клавиатуры с Windows

1. Включите клавиатуру. Если Bluetooth на ней включается отдельной кнопкой, включите его по инструкции к клавиатуре.
2. Откройте **Параметры → Bluetooth и устройства → Добавить устройство → Bluetooth**.
3. Выберите устройство с окончанием **`_BLE`**, например `SMK-37 Elite_BLE`. Это и есть MIDI.

Что нужно знать:

- В списке может быть второе устройство с тем же именем без `_BLE`. Это звук: клавиатура умеет работать как Bluetooth-колонка. Для MIDI оно не нужно. Если вы его подключили и звук ноутбука ушёл в клавиатуру, верните динамики в настройках вывода звука.
- После сопряжения под устройством написано **«Сопряжено»**, а не «Подключено». Это нормально: Bluetooth MIDI подключается только в момент, когда программа открывает порт.
- Клавиатура по Bluetooth работает только с одним устройством. Если она уже подключена к телефону или планшету, отключите её там.

## Шаг 2. Установка loopMIDI и создание порта

1. Установите loopMIDI. Проще всего командой в терминале (PowerShell):

   ```
   winget install --id TobiasErichsen.loopMIDI -e
   ```

   Либо скачайте установщик с сайта автора, Tobias Erichsen (tobias-erichsen.de). Windows попросит разрешение администратора — соглашайтесь, программа ставит драйвер виртуального порта.
2. Запустите loopMIDI.
3. В поле **New port-name** внизу окна впишите имя порта, например `SMK-37 BT`.
4. Нажмите кнопку **+**. Порт появится в списке «My loopback MIDI ports».

loopMIDI сам добавляется в автозагрузку и запоминает порт, так что этот шаг делается один раз.

## Шаг 3. Установка и настройка MIDIberry

1. Установите MIDIberry из Microsoft Store (поиск по названию) или командой:

   ```
   winget install --id 9N39720H2M05 --source msstore
   ```

2. Запустите MIDIberry.
3. В списке **INPUT** выберите `SMK-37 ..._BLE (Bluetooth MIDI IN)`.
4. В списке **OUTPUT** выберите порт из шага 2 — `SMK-37 BT`.
5. Включите переключатель **MIDI MONITOR**, чтобы видеть приходящие ноты.

Через пару секунд после выбора входа Windows установит связь с клавиатурой.

## Шаг 4. Проверка

Нажмите несколько клавиш. В MIDIberry внизу, в блоке **INPUT MONITOR**, должны побежать строки вида:

```
NoteOn , Ch: 15, Note: 60, Velocity: 127
NoteOff, Ch: 15, Note: 60, Velocity:  64
```

Если строки есть, мост работает и осталось настроить музыкальную программу.

## Шаг 5. Настройка музыкальной программы

Везде выбирайте вход **`SMK-37 BT`** (порт loopMIDI), а не «Bluetooth MIDI IN». Перед запуском программы MIDIberry уже должен работать.

Выход порта `SMK-37 BT` включать не нужно: всё, что программа в него отправит, вернётся ей же на вход, и ноты начнут дублироваться или зацикливаться.

Названия пунктов меню ниже могут немного отличаться в зависимости от версии программы. Сам мост до порта `SMK-37 BT` проверен; настройки внутри программ на моём компьютере не проверялись.

### Ableton Live

1. Откройте **Settings** (в старых версиях Preferences), клавиши `Ctrl + ,`.
2. Перейдите на вкладку **Link, Tempo & MIDI**.
3. В списке MIDI-портов найдите строку входа **Input: SMK-37 BT** и включите галочку **Track**. Галочка **Remote** нужна, только если вы хотите назначать ручки и кнопки клавиатуры на параметры Live.
4. В строке **Output: SMK-37 BT** все галочки оставьте выключенными.
5. Создайте MIDI-дорожку и положите на неё инструмент.
6. На дорожке в блоке **MIDI From** оставьте `All Ins` и `All Channels`, включите кнопку записи (Arm). Теперь клавиатура играет этим инструментом.

### FL Studio

1. Откройте **Options → MIDI Settings**, клавиша `F10`.
2. В разделе **Input** выберите в списке `SMK-37 BT` и нажмите **Enable**.
3. Тип контроллера (Controller type) оставьте `(generic controller)`.
4. В разделе **Output** порт `SMK-37 BT` не включайте.
5. Закройте настройки, выберите инструмент в Channel Rack и играйте: FL Studio направляет ноты в выбранный канал.

Если список устройств пустой, нажмите **Refresh device list** внизу окна.

### Cubase

Способ 1, через мост (как в остальных программах):

1. Откройте **Studio → Studio Setup**.
2. Слева выберите **MIDI Port Setup**.
3. Найдите строку входа (In) `SMK-37 BT`. В колонке **Visible** должна стоять галочка, в колонке **In 'All MIDI Inputs'** тоже.
4. У строки выхода (Out) `SMK-37 BT` снимите галочку **Visible**, чтобы случайно не выбрать его на дорожке.
5. Нажмите **OK**.
6. Создайте дорожку инструмента (**Project → Add Track → Instrument**). В инспекторе дорожки вход оставьте `All MIDI Inputs`, включите **Record Enable** или **Monitor**.

Способ 2, без моста. В том же окне **MIDI Port Setup** в Cubase есть галочка **Use Device 'WinRT MIDI'**. Она включает новый MIDI-интерфейс Windows, и тогда Cubase должен увидеть `SMK-37 ..._BLE (Bluetooth MIDI IN)` напрямую, без loopMIDI и MIDIberry. Я этот способ не проверял: если клавиатура в списке появилась и ноты идут, мост для Cubase не нужен; если нет, пользуйтесь способом 1. Одновременно оба способа не используйте: закройте MIDIberry, когда включаете WinRT MIDI, иначе две программы будут делить одно Bluetooth-подключение.

### Другие программы

В настройках MIDI выберите вход `SMK-37 BT`.

## Что делать каждый раз перед игрой

1. Включить клавиатуру.
2. Запустить MIDIberry и убедиться, что выбраны вход (`..._BLE`) и выход (`SMK-37 BT`). MIDIberry выбор не запоминает: после каждого запуска его надо делать заново.
3. Запустить музыкальную программу. Окно MIDIberry можно свернуть, но закрывать нельзя: без него ноты не идут.

loopMIDI запускается сам вместе с Windows.

Шаг 2 делает за вас скрипт [start-bridge.cmd](bridge/start-bridge.cmd) (в архиве релиза он лежит в папке `Bluetooth Bridge`). Запустите его двойным щелчком до музыкальной программы: он проверит порт, откроет MIDIberry и сам выберет вход и выход.

## После перезагрузки пропал порт `SMK-37 BT`

На Windows 11 с новой службой MIDI порт loopMIDI после перезагрузки иногда появляется под именем `loopMIDI Port` вместо своего. В окне loopMIDI имя при этом правильное, а программы видят чужое. Последствия:

- в MIDIberry в списке OUTPUT нет `SMK-37 BT`;
- музыкальная программа считает порт новым и теряет его настройки. В Ableton пропадают галочки Track и Remote, а у Control Surface в поле Input становится `None`.

Лечится перезапуском loopMIDI: закройте его через значок в трее (правая кнопка → Exit) и откройте снова. Скрипт `start-bridge.cmd` делает это сам, если не находит порт с нужным именем.

Музыкальную программу запускайте после того, как порт вернул своё имя. Если она уже была открыта, выберите в её настройках вход `SMK-37 BT` заново (в Ableton: **Settings → Link, Tempo & MIDI**, поле **Input** у Control Surface).

Другое имя порта или другая клавиатура задаются параметрами:

```
start-bridge.cmd -Port "Мой порт" -Keyboard "*Bluetooth MIDI IN*"
```

Ключ `-Reconnect` закрывает и открывает MIDIberry заново. Он пригодится, если после сна ноутбука ноты перестали идти.

### Автозагрузка

Чтобы мост поднимался сам при каждом входе в Windows, один раз выполните в папке со скриптом:

```
start-bridge.cmd -Install
```

Скрипт запишет себя в автозагрузку текущего пользователя (с теми же `-Port` и `-Keyboard`, если вы их указали). Через 20 секунд после входа он проверит порт и откроет MIDIberry. Клавиатура к этому моменту должна быть включена; если она была выключена, запустите `start-bridge.cmd` вручную, когда включите.

Убрать из автозагрузки: `start-bridge.cmd -Uninstall`. Если перенесёте папку со скриптом, выполните `-Install` ещё раз из нового места.

## На что обратить внимание

- **MIDI-канал.** Клавиатура может передавать не по первому каналу (у меня шла по 15-му). Если дорожка слушает только канал 1, звука не будет. Поставьте на дорожке приём со всех каналов или смените канал на клавиатуре.
- **Сила нажатия.** Если все ноты приходят с Velocity 127, на клавиатуре включена фиксированная громкость. Это меняется в настройках клавиатуры или в MidiSuite.
- **Задержка.** У Bluetooth MIDI она чуть больше, чем у кабеля. Для записи быстрых партий надёжнее USB.

## Ограничения

- Мост работает в одну сторону: от клавиатуры к компьютеру. MidiSuite нужна связь в обе стороны, поэтому для настроек и особенно для прошивки используйте USB-кабель.
- MIDIberry не запускается автоматически и не помнит выбранные вход и выход. Это закрывает скрипт `start-bridge.cmd`.

## Если что-то не работает

| Что происходит | Что проверить |
|---|---|
| Клавиатуры нет в списке «Добавить устройство» | Клавиатура включена и не подключена к телефону. В **Параметры → Bluetooth и устройства → Устройства** переключите «Обнаружение устройств Bluetooth» на **Расширенное**. |
| В MIDIberry нет входа `..._BLE` | Нажмите **List All Input Devices**. Если не помогло, удалите клавиатуру из Bluetooth-устройств Windows и выполните сопряжение заново. |
| В MIDIberry нет выхода `SMK-37 BT` | loopMIDI не запущен или порт не создан. Откройте loopMIDI и проверьте список портов. Если порт в loopMIDI есть, а в списке вместо него `loopMIDI Port`, см. раздел «После перезагрузки пропал порт». |
| В INPUT MONITOR пусто | Выбран ли вход `..._BLE`. Выключите и включите клавиатуру, выберите вход заново. |
| В MIDIberry ноты есть, в музыкальной программе нет | Запущен ли MIDIberry с выбранным выходом; включён ли вход `SMK-37 BT` в настройках программы; совпадает ли MIDI-канал. |
| Ноты дублируются или зацикливаются | Отключите `SMK-37 BT` как выход в музыкальной программе. |
| Нота «зависла» и звучит без конца | Кнопка **All Note Off** в MIDIberry. |
| После сна или перезагрузки перестало работать | Запустите `start-bridge.cmd -Reconnect`. Вручную: перезапустите MIDIberry и выберите вход и выход заново. |
| После перезагрузки в программе слетели настройки порта | Порт появился под именем `loopMIDI Port`, см. раздел «После перезагрузки пропал порт». |
